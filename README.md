# Dergs Standard Runtime (DSR)

A highly-opinionated luau runtime for specific tasks, written in Zig and C++.

A lot of the runtime code outside of libraries is derived from zune (although with changes to make it a bit simpler), although DSR takes a fundamentally different approach to libraries.
